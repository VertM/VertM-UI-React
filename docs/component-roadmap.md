# 组件路线图 · 对标 Ant Design 的缺口(P2,中长期)

> 目的:把"组件数量比 antd 少"的缺口显式化,按**竖排可行性 × 需求 × 工作量**分档,分期立项。
> **不追求 100% 对齐 antd**——竖排语境下部分组件价值低或代价过高,可长期不做。
> 现有 ~45 个组件清单见 `docs/documentation-site-plan.md` §7。

## 分档说明
- **竖排可行性**:高=天然适配竖排 / 中=需专门设计 / 低=竖排下体验存疑或需重构范式。
- **优先级**:P0 近期、P1 中期、P2 远期/立项、—=暂不做。

---

## Tier 1 — 近期(竖排可行 + 需求高 + 工作量可控)

| 组件 | 竖排可行性 | 工作量 | 说明 |
|------|-----------|--------|------|
| **InputNumber** | 高 | 小-中 | 数字输入,竖排下加减控制轴需定方向;需求高,先做 |
| **Slider** | 高 | 中 | 滑块天然是轴向控件,竖排下正好走纵轴,契合度高 |
| **Rate** | 高 | 小 | 星级沿列排列即可,改造小 |
| **Upload** | 中 | 中 | 上传按钮 + 文件列表,列表走竖排 List 复用 |
| **Image** | 中 | 中 | 图片 + 预览层;预览工具条方向需适配 |
| **FloatButton** | 中 | 小-中 | 悬浮按钮,定位与展开方向按竖排调整 |

## Tier 2 — 中期(竖排需专门设计,或需求中等)

| 组件 | 竖排可行性 | 工作量 | 说明 |
|------|-----------|--------|------|
| **Tree** | 中 | 中-大 | 树形缩进在竖排下方向要重定义(缩进走 inline 轴) |
| **TreeSelect** | 中 | 中-大 | 依赖 Tree + Select |
| **Cascader** | 中 | 中 | 多级面板的展开方向需设计 |
| **Transfer** | 中 | 中 | 双列表穿梭,方向按钮需适配竖排 |
| **Carousel** | 高 | 中 | 竖向轮播天然,契合竖排 |
| **ColorPicker** | 中 | 中 | 取色面板方向适配 |
| **Mentions** | 中 | 中 | 依赖竖排文本域 + 弹层定位 |
| **Tour** | 中 | 中 | 引导气泡的指向/步进方向需适配 |
| **QRCode** | 高 | 小 | 纯渲染,几乎无竖排问题 |
| **Watermark** | 高 | 小 | 水印,方向可选 |
| **Affix** | 中 | 小-中 | 吸附,竖排滚动轴需适配 |

## Tier 3 — 远期 / 需独立立项(竖排代价大,单独设计)

| 组件 | 竖排可行性 | 工作量 | 说明 |
|------|-----------|--------|------|
| **Table** | 低-中 | 特大 | 竖排下"行列"语义、表头、滚动、固定列都要重新定义,**必须独立设计立项**,勿并入常规迭代 |
| **DatePicker** | 中 | 大 | 日历面板 + 竖排排布 + 蒙历/公历,工作量大 |
| **TimePicker** | 中 | 中-大 | 依赖类日期面板逻辑 |
| **Calendar** | 中 | 大 | 同 DatePicker 面板问题 |

## 暂不做 / 价值存疑
- **Splitter/Anchor/Segmented 等**:已具备。
- antd 中与竖排语义冲突大、或 Web 竖排场景需求极低的,按需再评估,不强行对齐。

---

## 立项建议
1. **先落 Tier 1**:6 个组件独立、工作量小,能快速把组件数量往上抬,且都竖排友好。
2. **Tier 2 按需求择优**:优先 QRCode / Watermark / Carousel(易且竖排契合),Tree 系视是否有导航/数据展示需求再上。
3. **Tier 3 单独立项**:尤其 **Table**——先做一份《竖排表格设计规范》(行列语义、表头方向、滚动与固定),评审通过再开发,不要塞进组件文档迭代。
4. 每落一个新组件:同步补其组件页(按 `documentation-site-iteration-1.md` 任务 3 的模板)+ props JSDoc + demo ≥ 8。

## 复用基建(降低造新组件成本)
新组件应尽量复用现有能力,避免重造:
- 弹层/定位:`overlay`(Overlay/Tooltip/Portal/placement)
- 竖排文本与光标:`@vertm/core`(caret / line-break / normalize)
- 主题与令牌:`@vertm/tokens`(含竖排专属 token)、`appearance`
- 列表/选择骨架:`List` / `Select` / `Menu`
