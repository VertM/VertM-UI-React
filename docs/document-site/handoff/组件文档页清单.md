## 每页的章节结构

**沿用现有页面的结构，只插入「键盘」一节**，不要按设计稿 03 的 TOC 重排章节。
现有 frontmatter 用的是 `group:`，不是 `nav:`，保持不变：

```markdown
---
title: Button
group:
  title: 通用
  order: 1
---

# Button

导语：一句话说明。

## 何时使用                ← §8 Admonition，金标在右缘

## 基本用法                ← 各组件自己的能力演示，若干节

## 竖排提示

## 键盘                    ← ⚠️ 新增，必填

## API                     ← §7，由 dumi 从类型生成，不要手写

## 主题变量
```

子组件 API（如 `Button.Group`、`Form.Item`、`Menu.SubMenu`）照旧跟在 `## API` 后面。

### ⚠️ 「键盘」章节是必填项

竖排下的键盘行为与横排直觉不同，是用户最难自己发现的信息。

| 组件 | ↑ ↓ | ← → | 其他 |
|---|---|---|---|
| Select（关闭时） | ↓ 打开 | 竖排时 → 打开 | Enter 打开 |
| Select（打开时） | 上下移动高亮项 | 竖排：→ 确认、← 上一项；横排：→ 下一项、← 上一项 | Enter 确认，Esc 关闭 |
| Menu | 走同级 | → 进子菜单 / ← 回退到父级 | Enter / 空格 选中或展开 |
| Tabs | 仅当横排且标签栏在左右两侧时，用于切换 | 竖排时始终用于切换；横排且标签栏在上下时也用于切换 | Home / End 跳到首尾，Enter / 空格 激活 |
| Input（单行） | 在列内移动光标，Shift 扩选 | — | Enter 触发 `onPressEnter` |
| TextArea（多行） | 浏览器原生行为 | 浏览器原生行为 | — |

上表以外、源码里有 `onKeyDown` 的组件，写之前先读源码：
Button、Card、Collapse、Divider、Drawer、Modal、Pagination、Switch、Tag，
以及焦点陷阱 `hooks/useFocusTrap.ts`（Modal / Drawer 的 Tab 循环与 Esc 关闭）。
Dropdown 的下拉内容是 Menu 时，键盘行为同 Menu。

没有自定义键盘处理的组件，写一句"使用浏览器原生的 Tab / Enter / 空格 行为"，不要省略这一节。
