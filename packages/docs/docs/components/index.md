# 组件总览

按 Ant Design 习惯分组。点击进入详情页查看竖排 live demo 与 API。

## 通用

| 组件 | 说明 |
|------|------|
| [Button](/components/button) | 竖排按钮，支持列深与 Editorial 墨色主按钮 |
| [Icon](/components/icon) | 方向感知 SVG 图标 |
| [Typography](/components/typography) | 标题 / 正文 / 链接排版 |
| [ConfigProvider](/components/config) | 主题、书写模式、外观与全局配置 |
