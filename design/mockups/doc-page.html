Button 按钮ᠲᠣᠪᠴᠢ

竖排按钮。字符串子节点走 VertMText 渲染,文字自上而下,列向右推进。

何时使用

标记一个操作命令,响应用户点击行为。竖排布局下,按钮沿 block 轴(左→右)排列;主按钮在 editorial 下为墨色填充,default 下为品牌蓝。

竖排提示:承载 writing-mode 的节点上不要放 flex;多行标签用 columnDepth 限制列深,超出后换到下一列。

API

属性类型默认值说明
type'primary' | 'default' | 'dashed' | 'text' | 'link''default'设置按钮类型
size'small' | 'middle' | 'large''middle'按钮尺寸(竖排下为控件壳宽)
dangerbooleanfalse危险操作按钮
loadingbooleanfalse载入状态,inline-end 处显示 spinner
columnDepthnumber4单列最大行数,超出后换列
